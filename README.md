Python Fundamentals Assignment 1

Data Structures – Strings & Tuples

📌 Project Overview

This project is based on Python fundamentals, focusing on Strings and Tuples. It demonstrates basic string operations, indexing, slicing, string methods, tuple creation, concatenation, repetition, and accessing tuple elements.

🎯 Objectives

- Understand string concatenation.
- Perform string indexing and slicing.
- Use built-in string methods.
- Create and combine tuples.
- Repeat tuple elements.
- Access tuple elements using indexing and slicing.

🛠️ Technologies Used

- Programming Language: Python
- IDE:  VS Code 

📚 Topics Covered

1. String Concatenation

Combining two or more strings using the "+" operator.

2. String Slicing and Indexing

Accessing specific characters and extracting portions of a string using indexing and slicing.

3. String Methods

- "upper()" – Converts a string to uppercase.
- "lower()" – Converts a string to lowercase.
- "capitalize()" – Capitalizes the first character.
- "count()" – Counts occurrences of a character.
- "replace()" – Replaces a specified substring.

4. Tuples

- Tuple creation
- Tuple concatenation
- Tuple repetition
- Tuple indexing
- Tuple slicing
